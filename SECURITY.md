# Security Policy

## Supported versions

Security fixes target the latest Chrome Web Store release and the current
`main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/thiagocbarreto/native-html-preview-for-github/security/advisories/new).

Include:

- Affected URL or file shape without private repository content
- Steps to reproduce
- Expected and observed sandbox behavior
- Impact on GitHub data, extension data, or outbound network access
- A minimal proof of concept when safe

Reports involving sandbox escape, GitHub session access, silent data transfer,
or Chrome Web Store policy bypass take priority.
